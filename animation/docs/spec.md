## 10. 不能混淆的边界

### 栈帧与缓冲区

栈帧保留原 main→caller→add 实测，结果 5，地址／源码／反汇编来自采样。缓冲区本轮是独立受控 ELF：buf 初始化为 CC；本次对齐布局中 rbp／返回槽距 buf 为 16／24B，由实际 GDB 校验，不推广为默认 ABI 局部空间。

三个输入分别在不同进程采集，ASLR 地址可不同。AD DE 00 改低字节，实际坏目标保留原高位，不再用示意 0x4015→0xDEAD 冒充。写入、ret 使用和取指 SIGSEGV 分开。越界为 C 未定义行为，不保证其他编译／机器相同。

### 递归

256KiB 是本实验主动设置的进程局部栈上限，不是宿主默认值。实测完整层数与失败回溯来自记录；八个图形是代表帧，不是最大深度。正常返回来自另一次 bounded 运行，四层、sum=10，不暗示溢出后恢复。

### Cache、调度、物理页与 TLB

实际 C 读取、PID、变量和信号使过程具体，但不能声称 GDB 读取了硬件 Cache／TLB 或完整 PFN、内核页表／调度。Cache 的 4组×2路×8B 与 LRU 是机制模型；CPU 令牌与两种示意调度不是完整内核追踪。

fork 同 VA／maps 和私有值隔离不直接证明物理同页／COW；物理 A/B/S、页表与 task/mm/内核栈为解释模型。VM 实机 4KiB 与模型 64B 分开；首次匿名读可使用共享零页，present 变化不证明新私有页分配。冷页被程序访问前不由 GDB 提前读取，minor-fault 增量也不当作纯硬件计数或耗时。
