# 独立导读章：OS 与程序运行基础（先分镜，后实现）

## 本轮授权与术语

用户新增授权：单独一章介绍 OS 基础、进程内存分布、进程的虚拟化视图、父子地址空间、编译／汇编／链接／装载、可重定位文件结构和 x86 寄存器；内存用竖向分块数组表现。新增 chapter0 独立导读，不改原七片的节奏与范围。

“可重定向文件”按 ELF **可重定位目标文件 .o** 理解，不与 shell 标准输入／输出重定向混为一谈。“虚拟进程”解释为 OS 提供的进程抽象、虚拟地址空间和可恢复 CPU 上下文，不虚构一种叫虚拟进程的硬件实体，也不等同虚拟机。

基准为 Linux x86-64 / ELF64 / 小端 / SysV 函数调用约定。无配音、纯黑白字、大寄存器、独立构图、可回退教学时钟。6 部短片构成一章，不把全部知识挤进一张全景图。

## 内存的统一视觉语法

- 所有新内存图均为**竖向连续分块数组**，顶端高地址、底端低地址；固定标注“虚拟地址 ↑ 增大”。栈一般向低地址（下）扩展、传统 brk 堆一般向高地址（上）扩展；mmap／malloc 实际位置不能套用固定保证。
- 每个分块有名称、当前进程身份、实际地址／区间和用途。未画的巨大空洞明确折叠，比例不是实际大小，不把用户 VA 画成整台物理 RAM，也不把保留区域说成全部驻留。
- ELF 文件另用竖向**文件**数组，明确“磁盘文件，offset 向下增大”；不是内存地址图。section、segment、链接时 VA、实际运行 VA 分别命名。
- 字节近景仍竖向排列：最高地址在上，最低地址在下；小端的低有效字节位于最低地址，不能为了好看颠倒实际字节序。
- 父子进程用两条独立竖向数组并排，标题各带真实 PID，相同 VA 对齐只表示各自地址空间中的对应位置；物理框示意用另一条单独标注的竖向数组，不冒充实测 PFN。

## 配套受控实验

新增 os-main.c、os-math.c、os-demo.h 三文件完整程序。用 gcc -E / -S / -c 与实际链接保留 .i/.s/.o 的摘要和可核对工具输出；readelf、objdump、nm 观察 ET_REL、ET_DYN PIE、符号、节、段和真实重定位。选择 main.o 对 os_data 的 PC32 引用，验证链接器写入的四字节等于 S+A-P，不把链接时地址冒充进程地址。

GDB 保留 ASLR：两次 inspect 运行分别观察动态解释器入口、应用 _start、main 入口、初始化完成的布局、os_add 的入口／ret、子寄存器宽度和 cmp 后标志；fork 运行用管道依次采父前／子前／子改后／父同步后。程序只访问自己分配的内存，检查错误，禁用本进程 core；不改宿主 sysctl／保护。保存源码／ELF／目标文件 SHA、完整命令、工具版本、ASLR 与原始输出，采集失败报错，不能造数据补齐。
